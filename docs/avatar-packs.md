# Avatar packs (bring your own animation library)

The assistant's character on the glasses (the big portrait on the assistant screen, the call portraits, the
small rail icon) comes from an **avatar pack**. The phone app, the browser simulator and the web HUD all read
the same format, so a pack you design in the simulator looks the same on the lens.

A pack is two files in one folder (or one `.zip`):

```
my-pack/
  manifest.json   schema 1, described below
  atlas.png       every frame, packed into a grid of equal cells
  LICENSE.txt     optional, kept on import
```

The repository ships one pack: an original one-bit orb face, CC0, generated by
[`tools/avatar/make_placeholder_pack.mjs`](../tools/avatar/make_placeholder_pack.mjs) into
`android/app/src/main/assets/avatar/default/` and `simulator/avatar/default/` (byte-identical copies; a unit
test checks that). It draws 15 states and reaches every other state through fallbacks.

## Manifest (schema 1)

```json
{
  "schema": 1,
  "id": "my-pack",
  "name": "My avatar",
  "license": "CC-BY-4.0",
  "cell": { "w": 192, "h": 288 },
  "atlas": { "file": "atlas.png", "cols": 8 },
  "portraitCrop": [16, 50, 160, 160],
  "threshold": 100,
  "states": {
    "idle":      { "playback": "loop", "frames": [{ "cell": 0, "ms": 350 }, { "cell": 1, "ms": 350 }, { "cell": 2, "ms": 450 }] },
    "speaking":  { "playback": "loop", "frames": [{ "cell": 3, "ms": 200 }, { "cell": 4, "ms": 200 }] },
    "asking":    { "playback": "once_then_hold", "frames": [{ "cell": 5, "ms": 350 }, { "cell": 6, "ms": 450 }] },
    "dancing":   { "playback": "bounded_loop", "boundedLoopSeconds": 4, "frames": [{ "cell": 7, "ms": 300 }, { "cell": 8, "ms": 300 }] }
  },
  "fallbacks": { "compressing": "working", "checking_watch": "waiting" }
}
```

| Field | Meaning |
|---|---|
| `schema` | Must be `1`. |
| `id` | Lowercase letters, digits, `.`, `_`, `-` (max 64). Imported packs live in `filesDir/avatar/<id>/`; importing a pack with the same id replaces it. |
| `name`, `license` | Shown on the phone's Settings page and in the simulator toolbar. Use an SPDX id. |
| `cell` | Size of one frame, 8..1024 px each way. Any size works; **2:3 (for example 192 × 288) is recommended** because the app draws at 128 × 192, 48 × 72, 32 × 48 and 24 × 36. |
| `atlas` | `file`: a PNG next to the manifest (no paths). `cols`: cells per row. Cell `k` is at column `k % cols`, row `k / cols`. The atlas must be at least `cols × cell.w` wide and tall enough for the highest cell used. |
| `portraitCrop` | `[x, y, w, h]` inside a cell: the square-ish region of the **idle** state's first frame used for the rail/menu portrait. Default: a centred square at the top of the cell. |
| `threshold` | 1..255. A source pixel is "on" when its **green** channel is at least this (default 100). Draw light-on-black; pure green (`#00ff00`) or white both work. |
| `states` | Map of state name to clip. Only `idle` is required (without it the first state is used as idle). |
| `fallbacks` | Map of state to the state to show instead when the pack does not draw it. |

Each clip has `playback`, `frames` (`cell` index and duration `ms`, 1..60000) and, for `bounded_loop`,
an optional `boundedLoopSeconds` (default 3).

### Playback policies

Time is measured from the moment the app entered the state (`elapsed = now − since`, never negative).

| `playback` | Behaviour |
|---|---|
| `loop` | Repeats forever (`elapsed mod clip length`). |
| `subtle_loop` | Same timing as `loop`; for calm ambient moods. |
| `bounded_loop` | Loops while `elapsed < boundedLoopSeconds`, then shows the frame that `elapsed` reaches without looping (normally the last frame) and holds it. |
| `once` | Plays through once and holds the last frame. |
| `once_then_hold` | Same timing as `once`; use it for states meant to stay on screen (asking, saving). |

These are exactly the timings the app used before packs existed. The reference implementation is
`AvatarClip.frameIndex` in `android/app/src/main/java/io/lampyr/glasses/render/avatar/AvatarManifest.kt`;
the simulator (`avatarCell`) and HUD (`animationFrame`) mirror it and are covered by tests.

### Scaling

Frames are reduced to one bit by OR-pooling: each destination pixel is lit when any source pixel it covers
passes `threshold`. Thin strokes survive at small sizes. The app keeps the last 32 scaled frames in an LRU
cache, so a pack costs one decoded atlas in memory plus a few small bitmaps. Packs are limited to 16 MB.

`JoyCallLongCallsTest` keeps them in step.

A useful minimal pack draws the **core states**: `idle`, `listening`, `thinking`, `speaking`, `working`,
`error`, `happy`. Everything else then has a fitting stand-in.

## How fallbacks are chosen

For a requested state `s` the app shows the first of:

1. `s` itself, if the pack has it;
2. otherwise `fallbacks[s]` from the manifest, followed recursively (cycles are cut);
3. otherwise the built-in fallback in the table above (`AvatarStates.BUILTIN_FALLBACKS`), followed recursively;
4. `idle`;
5. the pack's first state.

If the pack itself cannot load (missing files, bad JSON, atlas too small), the app uses the bundled
placeholder; if even that fails it draws a plain ring with two eyes. The glasses never lose the avatar.

## Building a pack from GIFs or PNG sequences

[`tools/avatar/pack_from_frames.py`](../tools/avatar/pack_from_frames.py) turns a folder of frames into
`manifest.json` + `atlas.png`:

```
frames/
  idle/00.png idle/01.png idle/02.png
  listening/00.png ...
  thinking.gif            # an animated GIF works too; its frame durations are kept
  pack.json               # optional: id, name, license, portraitCrop, threshold, per-state overrides, fallbacks
```

```sh
uv run tools/avatar/pack_from_frames.py frames out/my-pack --license CC-BY-4.0
(cd out/my-pack && zip -r ../my-pack.zip manifest.json atlas.png)
```

Options: `--cell 192x288` (resize every frame), `--cols 8`, `--ms 350` (duration for PNG frames),
`--cut 100` (brightness threshold), `--green` (threshold the green channel), `--invert` (dark-on-light
artwork), `--strict` (reject non-canonical state names). Without overrides each state gets the playback
policy the app expects (for example `asking` holds, `error` plays once, `listening` loops). Per-state overrides
in `pack.json` look like `"states": {"dancing": {"playback": "bounded_loop", "boundedLoopSeconds": 4, "ms": [300, 300]}}`.

Tips: draw bright lines on black, keep strokes at least 4–6 px at 192 × 288 so they survive the 24 × 36 call
portrait, and leave the face inside the `portraitCrop` square. Preview in the simulator before loading it on
the phone.

## Loading a pack

- **Phone:** Settings → Avatar → **Import zip** (Storage Access Framework picker) or paste an https URL and
  **Load URL** (a `.zip`, or a `manifest.json` whose atlas sits next to it). The pack is validated, copied into
  `filesDir/avatar/<id>/` and the setting `avatar.pack` becomes `file:<id>`; the glasses switch immediately.
  **Reset** returns to the bundled placeholder (`avatar.pack = default`). Downloads happen once, at import;
  nothing is fetched while drawing.
  Code hooks: `AvatarPackStore.importPackFromZip(uri)`, `importPackFromUrl(url)`, `resetToDefault()`,
  `currentPack()`, `currentInfo()`, and `GlassesService.reloadAvatar()`.
- **Simulator:** `simulator/index.html?avatar=<url>` (a pack folder, a `manifest.json` or a `.zip`), or the
  **load avatar pack…** link in the display toolbar (pick a `.zip`, or `manifest.json` together with its atlas).
- **Web HUD:** `hud/index.html?avatar=<pack folder or manifest.json URL>`.

## Regenerating goldens after changing the bundled pack

```sh
node tools/avatar/make_placeholder_pack.mjs
python -m http.server 8765 --directory simulator &
GOLDEN_ONLY=apps,joy,joy-menu,joy-thinking-reply,joy-call-listening,joy-call-thinking,joy-call-speaking,joy-call-muted,joy-call-turns,joy-call-worker,joy-call-compact-listening,joy-call-compact-speaking,joy-call-compact-muted,joy-call-compact-worker,joy-call-compact-reconnecting \
  UPDATE_GOLDEN_COVERAGE=1 uv run --with playwright --with pillow python android/tools/capture_goldens.py
cd android && UPDATE_RASTER_GOLDENS=1 ./gradlew :app:testDebugUnitTest --tests 'io.lampyr.glasses.render.RasterGoldenTest'
```

The simulator is the golden source; `RenderingGoldenTest` then checks the Kotlin renderer against it (0.5%
threshold). `UPDATE_BITMAP_GOLDENS=<comma list>|all` regenerates bitmap goldens from Kotlin instead, when no
browser is available.
